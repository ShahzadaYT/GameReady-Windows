# TravelReady 0.4.0

The first public release of **TravelReady**, the current version of this
project. It checks, before you travel, that the games on your Windows handheld
will start without an internet connection, and it can apply safe per-game
settings recommendations.

TravelReady replaces the earlier 0.1.x downloads from this repository,
`GameReady.exe` (v0.1.0) and `GameLaunchTester.exe` (0.1.1). Those were built
from earlier code that is not in this repository. You can delete them;
TravelReady does not need them.

## Download

Download **`TravelReady.exe`** below. It is a single portable program: no
installer and nothing else to download.

- **Requires** Windows 10 or 11, 64-bit.
- **SmartScreen:** the program is not code-signed yet, so Windows may say
  "Windows protected your PC". Choose **More info**, then **Run anyway**.
- **Checksum:** the SHA-256 of `TravelReady.exe` is listed on the release page.
  Check it in PowerShell with `Get-FileHash .\TravelReady.exe -Algorithm SHA256`.

Getting started, troubleshooting and removal are in the
[README](../../README.md#download-and-run).

## What it does

- Finds installed games from Steam, Xbox / Game Pass, EA, Epic, Ubisoft, GOG
  and Battle.net, and groups them by launcher
- Starts each game the way its launcher would, confirms it really started,
  and closes it again
- Shows a readiness verdict per game, with the reason and what to do
- **Prepare for Travel** checks everything that is not ready, lists the games
  it will start and asks first, and can be resumed if interrupted
- Compares game settings with community recommendations from ROG Ally Life
  (not ASUS) and applies only changes it classifies as safe, after showing the
  exact change and taking a verified backup
- In-app **Diagnostics**, plus a log you can save with your account name
  removed

It does not bypass DRM, launcher sign-in or anti-cheat, and it never changes
device-wide settings such as TDP or Windows power plans.

## Changes in the last cycle

- The test suite now passes on Windows, and Windows CI is green
- On the test machine, the window opens in about 2 s instead of about 18 s with a large Xbox
  library. Launcher detection is done once per launcher, not once per game.
- After a scan, launchers are checked again, so a newly installed launcher is
  recognised
- A failed or timed-out Xbox check is reported as "cannot determine" instead
  of "not installed"
- CI moved off the deprecated Node.js 20 GitHub Actions runtime
- Command output redirected to a file is written as UTF-8. Before this,
  `TravelReady.exe doctor > doctor.txt` and `scan` stopped with an "Unhandled
  exception in script" error. `TravelReady.exe` is a windowed program, so typed
  into a terminal it still shows no output; redirect it, or use **Diagnostics**.
- Released under the MIT licence (`LICENSE`)

## Known issues

- **Text can look small on scaled displays**, for example at 150%, which is
  the ROG Ally's default.
- **Not yet tested on an ROG Ally.** Tested on a Windows 11 desktop and on
  GitHub's Windows build machines. Touch use, launching real Xbox and EA
  games, and applying settings on the device are still to be confirmed.

## Tested

- Automated suite on Windows and Ubuntu, Python 3.11 and 3.12: all four CI
  jobs green. GUI tests run on Windows only. Hardware-dependent tests are
  listed in `docs/HARDWARE_VALIDATION.md` and are not part of CI.
- The packaged `TravelReady.exe`, run from a folder outside the source tree on
  Windows 11: the window opens; `--version` reports 0.4.0; launcher detection
  and a scan find installed games; it writes only to its own data folder.
